راهنمای راه‌اندازی نسخه آنلاین انبار هیئت مهدیار
=================================================

این بسته از نسخه قبلی برنامه و لوگوی اصلی گروه ساخته شده است. امکانات محلی قبلی حفظ شده‌اند.
برای همگام‌سازی واقعی بین چند گوشی، باید یک پروژه Supabase متعلق به خودتان بسازید؛ این مرحله بدون دسترسی به حساب شما قابل انجام نیست.

۱) در supabase.com یک پروژه جدید بسازید.
۲) از Project Settings > API مقدار Project URL و anon/public key را بردارید.
۳) فایل cloud-config.js را باز کنید و دو مقدار زیر را جایگزین کنید:
   MAHDYAR_SUPABASE_URL
   MAHDYAR_SUPABASE_ANON_KEY
   کلید service_role را هرگز در این فایل قرار ندهید.
۴) در Supabase بخش SQL Editor، کد فایل supabase-setup.sql را اجرا کنید.
۵) در Authentication > Providers > Email، ورود با ایمیل/رمز را فعال کنید و تأیید ایمیل را برای این حساب غیرفعال کنید (چون حساب با شناسه داخلی استفاده می‌شود و ایمیل واقعی نیست).
۶) در Authentication > Users یک کاربر بسازید:
   ایمیل داخلی: tabligat@mahdyar.app
   رمز: یک رمز قوی حداقل ۸ کاراکتری که خودتان انتخاب می‌کنید.
   این ایمیل برای ورود داخلی است و صندوق پستی واقعی نیست.
۷) فایل‌ها را در ریشه مخزن GitHub Pages جایگزین کنید. cloud-config.js را هم همراه بقیه فایل‌ها بارگذاری کنید.
۸) هر گوشی همان نام کاربری «تبلیغات» و همان رمز را وارد کند. نشست ورود روی هر دستگاه ذخیره می‌شود و پس از بستن برنامه باقی می‌ماند تا زمان خروج یا لغو نشست.

تاریخ‌ها:
تاریخ‌ها در فرم‌ها به هجری شمسی وارد و نمایش داده می‌شوند؛ در داده‌های داخلی به شکل استاندارد میلادی ذخیره می‌شوند تا مرتب‌سازی و همگام‌سازی درست بماند. منطقه زمانی محاسبات روی Asia/Tehran است.

اثر انگشت:
ورود بیومتریک/Passkey هنوز فعال نشده است. فعال‌سازی امن آن به پیکربندی جداگانه WebAuthn و تأیید سمت سرور نیاز دارد؛ این نسخه به‌جای شبیه‌سازی ناامن اثر انگشت، نشست ورود را روی دستگاه نگه می‌دارد.

نکات مهم:
- تا وقتی تنظیمات Supabase را وارد و حساب را ایجاد نکرده‌اید، ورود آنلاین کار نمی‌کند.
- داده‌های موجود در مرورگر قبلی به‌صورت خودکار به سرور منتقل نمی‌شوند؛ پس از اولین ورود، اگر جدول آنلاین خالی باشد، داده‌های محلی همان دستگاه به‌عنوان داده اولیه بارگذاری می‌شوند. قبل از آن از بخش پشتیبان‌گیری خروجی بگیرید.
- هر گوشی باید از همان آدرس GitHub Pages استفاده کند.
- برای خروج از همه دستگاه‌ها، در پنل Supabase نشست‌های کاربر را لغو کنید و رمز را تغییر دهید.
